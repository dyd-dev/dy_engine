# Dense Arena

Kenney Tiny Dungeon의 방·가구·적 스프라이트와 자체 픽셀 탄환·파편을 공통 `dyf::Scene` / `Renderer`로 그리는 밀집 게임 장면이다. 연결된 방 9개에서 적, 탄막, 파편이 결정론적으로 순환한다. 기본 동적 풀은 적 600개·탄환 4,500개·파편 900개이며 바닥·벽·소품·플레이어는 별도다. 충돌 판정이나 실제 게임 플레이를 구현한 것은 아니다.

```sh
./build/arena --assets /home/suhan/dev/assets/kenney_tiny-dungeon
./build/arena --objects 12000 --paused
```

`DY_DENSE_ARENA_ASSETS` 빌드 정의가 있으면 `--assets`를 생략할 수 있다. 경로는 압축 해제한 Tiny Dungeon의 `Tiles/` 상위 폴더다. 에셋은 저장소로 복사하지 않는다.

- Space: 게임과 카메라 이동 일시정지. 렌더링은 계속한다.
- R: 동일한 초기 상태에서 재시작.
- O: 중앙 방 근경 / 모든 방 전체 보기. 창 종횡비에 맞춰 직교 투영한다.
- 4: CPU 프러스텀 컬링.
- 5: 인스턴싱. 같은 메시·재질의 인접 엔티티를 묶어 그린다.
- 6: RenderGraph 병렬 명령 기록.
- F5: 현재 게임·카메라를 고정하고 인스턴싱 OFF 기준 측정.
- F6: F5 때의 게임·카메라로 복귀하고 인스턴싱 ON 비교 측정.
- F7: 측정 취소·결과 삭제.
- V: VSync. 표시 주기 제한과 렌더링 비용을 구분할 때 사용한다.
- M: 제출 프레임 수, draw·instance·컬링 수를 콘솔에 표시.
- F11: 공통 profiler 표시. Escape: 닫기.

F5 → 기준 수집 완료 → F6 순으로 A/B를 수집한다. 각 측정은 최소 1초·10제출 프레임 준비 후 최소 3초·30제출 프레임을 수집한다. 큰 프로파일러 HUD는 두 수집에서 자동으로 숨기고 같은 작은 진행 표시를 그린다. 계측은 계속하며 F11로 패스별 내역을 다시 연다. 화면 하단에 결과를 표시하고 CPU 작업·대기, GPU와 패스 시간, draw·instance·triangle 수를 콘솔에 출력한다. 측정 중 카메라·설정·창 크기·초점이 바뀌면 취소한다. F6는 인스턴싱 외의 조건이 기준과 다르면 거절한다. 두 측정이 끝나도 정지 상태를 유지하며 Space로 재생한다. VSync ON이면 표시 주기 제한으로 프레임 시간 변화가 가려질 수 있으므로 CPU 작업·GPU 시간도 함께 읽는다. 이 비교는 같은 정지 상태의 렌더링 비교이며 게임 시뮬레이션 비용의 최적화 수치는 아니다. 출력 최대 프레임 시간은 관측 최대이며 p95/1% low를 측정하지 않는다.

공통 CPU WORK는 렌더러 prepare·record·submit만 포함하며 게임 상태 계산은 제외한다. GPU SPAN은 프레임 데이터 업로드부터 그래프 종료까지의 경과 시간으로 큐의 빈 시간도 포함할 수 있다. 실제 GPU 패스별 시간과 함께 해석한다. GPU timestamp 미지원·미완료 결과는 N/A다. 현재 빌드는 Wayland/Vulkan이며 실행 화면·성능 수치는 이번 작업에서 측정하지 않았다.

4의 컬링은 Space로 상태를 고정해 수동 비교한다. 인스턴싱은 draw 수와 CPU 제출 비용을 줄이며, 같은 물체의 픽셀·정점 처리량까지 없애지는 않는다. 컬링은 화면 밖 방과 물체의 불필요한 그리기를 줄인다. CPU 컬링이며 GPU 컬링이나 indirect 시연으로 표기하지 않는다.

종류별 메시·재질·이미지와 엔티티를 시작 시 만들고 `Scene::AddInstance`로 geometry를 공유한다. 매 프레임 변경하는 것은 고정 풀의 변환이다. 수명 종료는 같은 풀 항목의 위치·크기를 재사용한다. 별도 셰이더·GPU 자원 생성·백엔드별 게임 경로는 추가하지 않았다. 조명과 HDR을 끈 alpha-mask 쿼드 경로를 사용한다. 공통 렌더러의 linear sampler를 사용하므로 엄밀한 nearest-neighbor 픽셀 필터는 아니며, 개별 PNG를 사용해 atlas의 인접 타일 번짐을 피한다.
