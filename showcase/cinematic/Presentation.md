# 90초 연속 소개 영상 시연

**`presentation.exe` 하나를 실행하면 같은 창에서 Bistro Exterior → Bistro Interior → Emerald Square가 각각 30초씩 자동 재생됩니다.**
처음에 세 장면의 에셋·GPU 자원·효과를 미리 준비합니다. 준비 중에는 불투명 로딩 화면으로 효과 전환을 가립니다. 이후에는 같은 장치와 창에서 준비된 장면을 재사용하며, 각 장면의 30초가 끝나면 1초 유지한 뒤 다음 장면으로 넘어갑니다.
준비 시간은 재생 시간에 포함되지 않습니다. 두 번의 장면 전환 대기를 포함한 재생 시간은 약 92초입니다.
마지막 Emerald는 OFF 상태의 장면을 유지합니다. 기존 실행 파일에서도 `showcase.exe --presentation-all`로 동일하게 시작할 수 있습니다.

각 에셋만 따로 촬영하고 싶을 때는 아래 바로가기를 사용합니다.

ShowcaseCinematic을 빌드하면 Windows 실행 파일 옆에 다음 바로가기가 생성됩니다.

- `Demo-exterior.cmd`: Bistro Exterior — 조명, 그림자, 짙은 볼륨 안개, 와이어프레임, 법선 뷰
- `Demo-interior.cmd`: Bistro Interior/Wine — 직접광, 강조한 Bloom, 투명·굴절, 점광원 그림자, 법선 뷰
- `Demo-emerald.cmd`: Emerald Square — 실제 메시 LOD 전환과 단계 색상, 와이어프레임, 거칠기 뷰, GPU 패스, CPU 단계

직접 실행할 때는 `showcase.exe exterior --presentation`처럼 장면과 옵션을 지정합니다.
`interior`, `emerald`도 동일합니다. 기존 `--profile`, `--1080p`, `--start N`, `--paused`를 함께 사용할 수 있습니다.
`--presentation` 없는 실행은 기존 수동 시연입니다.

각 기능은 **2초 OFF → 2초 ON → 2초 OFF 유지**이며, 5개 기능을 합쳐 30초입니다.
긴 프레임이 발생해도 상태를 건너뛰지 않으며, 변경된 화면을 제출한 뒤부터 다음 표시 시간을 계산합니다. 초기 파이프라인 준비가 ON 표시 시간을 소모하지 않게 합니다.
이전 기능의 설정은 다음 기능에서 장면 기본값으로 복원됩니다. 원본 에셋의 카메라 동선을 사용합니다.
프로파일러와 법선 뷰는 같은 타이밍으로 표시/숨김을 전환합니다.
마지막에는 OFF 상태로 정지합니다. 로딩·최소화 시간은 시연 시간에 포함되지 않습니다. 자동 시연은 다른 창에 포커스가 가도 계속 진행되며 Space로 직접 일시정지할 수 있습니다.

자동 시연에서는 SSAO·SSGI·TAA·Hi-Z·SSR·환경광 분리를 제외했습니다. AO·SSGI·SSR·Hi-Z는 실제 기본 렌더 설정에서도 끕니다. 세 장면을 동시에 유지하므로 소개 영상 모드의 재질 텍스처는 최대 1024px로 제한합니다. 원본 에셋 파일과 메시를 변경하지 않으며, 일반 실행과 벤치마크 설정은 유지합니다.
안개 밀도는 0.04, Bloom 강도는 0.25로 해당 구간에서만 강조합니다.
법선·거칠기 색상은 진단 화면이며 화질 개선 전후가 아닙니다. LOD 구간은 허용 오차 8px에서 원본 메시와 실제 LOD 메시를 전환하고 단계별 색상으로 보여줍니다.
와이어프레임 미지원 장치에서는 법선 뷰로 대체합니다. 자동 시연은 공간 프로브 3회 캡처를 생략하며 실내의 기본 환경광용 방 프로브는 유지합니다.

| 조작 | 동작 |
| --- | --- |
| Space | 카메라와 시연 일시정지 / 재개 |
| R | 연속 재생에서는 Bistro부터 전체 재시작; 단일 장면 실행에서는 현재 장면 재시작 |
| ← / → | 시연 시간 6초 이동 |
| Home / End | 시작 / 마지막 OFF 상태 |
| H | 자동 전환 / 수동 조작 전환 |
| Tab | 자유 카메라 전환; 자유 카메라 중 시연 타이머 정지 |
| F11 | 프로파일러 표시 / 숨김; 직접 조작 시 자동 전환을 중단하고 수동 모드 진입 |
| Escape | 열린 패널 닫기, 이후 창 종료 |

자동 시연에서는 정지된 A/B 사전 측정을 수행하지 않습니다. 필요할 때 H로 수동 모드에 진입한 뒤 기존 F5/F6 비교를 사용할 수 있습니다.
프레임 처리량은 VSync 등 실행 조건의 영향을 받으며 GPU span은 디스플레이 지연 시간이 아닙니다.
GPU 경로의 가시 객체·삼각형 수는 읽어오지 않으므로 기존 UI처럼 N/A로 표시합니다.

벤치마크 CSV 모드·카메라 내보내기·야간 프리셋은 자동 시연과 함께 사용할 수 없습니다.

`presentation.exe --presentation-verify`는 마우스·키보드 입력 없이 같은 순서를 재생하고 프레임 시간을 로그로 남긴 뒤 종료하는 검증 모드입니다.
