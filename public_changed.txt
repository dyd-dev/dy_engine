Public 변경 현황

기준: main / 7561c22, 2026-10-26 정리 후 작업 트리
이 파일은 실제 차이의 기록이며 Public 변경의 허가나 정당화 근거가 아니다.
기존 API로 해결하는 것을 우선하고, 새 타입·함수·옵션과 문서 변경을 최소화한다.
이전 기록: refs/backup/public-changed-before-cleanup-20261026

이번에 제거하거나 내부로 옮긴 변경
- 미사용 DevicePresentationObserver 및 등록 API와 callback 상태 제거.
- 미사용 Window::CloseRequestHandler 및 등록 API 제거.
- 미사용 ModelRenderer::RenderToTexture, Renderer의 draws 오프스크린 오버로드 제거.
- 미사용 ModelRenderer::GetCpuPrepareMilliseconds 및 전용 타이머 제거.
- ModelCamera, 카메라 배열, 원본 축·단위 metadata와 전용 importer 코드 제거.
- cacheSkinTransforms 공개 옵션 제거. 정확한 캐시는 내부 기본 최적화로 유지.
- ModelRenderer의 추가 캐시·revision 저장소는 기존 opaque ProfilingState로 이동.
- UsesBlendedRendering은 기존 비공개 SceneAlgorithms.h로 이동. Material.h는 main과 동일.
- 이미지 크기 제한 overload 3개는 기존 비공개 ImageDds.h로 이동.
- HUD의 Details/Default 입력 상태는 비공개 Renderer::Impl에만 추가.

남은 변경과 이유
1. src/Public/dyf/Extends/ImGui/ImGui.h
   GLFW callback 결합 대신 공통 Window 입력을 사용하는 계약과 private 생성자 변경. 공개 함수 서명은 유지.
2. src/Public/dyf/Extends/Model/Model.h
   원본 재질의 알파·양면·UV·packed texture 의미를 명시하는 옵션과 maxTextureDimension. 기존 기본 API는 유지하되 구조체 크기는 달라진다.
3. src/Public/dyf/Extends/Model/ModelRenderer.h
   CPU skinning enum 값과 실제 변형 이력 슬롯 수명 주석. 추가 private 캐시는 헤더에 노출하지 않는다.
4. src/Public/dyf/Image.h
   원본 DDS BC mip 저장소를 공유하는 private 상태와 내부 friend. 기존 이미지 로딩 함수 서명은 유지.
5. src/Public/dyf/Mesh.h
   실제 정점 RGBA 및 64바이트 레이아웃에 맞춘 주석 수정.
6. src/Public/dyf/Platform/Window.h
   Android/iOS native surface 주소 재사용을 구별하는 GetSurfaceGeneration. 새 close callback API는 제거.
7. src/Public/dyf/RHI/Format.h
   BC1/BC3 linear·sRGB 포맷과 블록 크기 helper. 기존 enum 값은 유지.
8. src/Public/dyf/RHI/ICommandList.h
   기록 인자의 반복 할당을 줄이는 private 명령 저장소.
9. src/Public/dyf/RHI/IDevice.h
   owner thread·불변 resource snapshot에 필요한 private 상태와 BC upload·비동기 Present 계약. observer API는 제거.
10. src/Public/dyf/RHI/RenderGraph.h
    반복 resource use 탐색을 줄이는 private 평탄 저장소. 공개 호출 방식은 유지.
11. src/Public/dyf/RHI/Shader.h
    기존 binary CreateShader 입력을 유지하고 선택적 Vulkan GLSL CompileShader 입력을 제공. 소비자에게 CMake 실행을 요구하지 않으며 컴파일러 포함 여부는 라이브러리 빌드 시 결정한다.
12. src/Public/dyf/RenderExtension.h
    공유 BRDF 입력, direct instanceCount, 선행 깊이 완성 opt-in. 렌더 확장이 실제로 보장한 입력만 재사용한다.
13. src/Public/dyf/Renderer.h
    custom shadow coverage opt-in과 실제 정점·프로파일링 계약. 신규 offscreen overload는 제거.

호환성과 확인 범위
- private 필드도 포함한 클래스·공개 구조체의 레이아웃 변경이 남아 있어 기존 바이너리와의 ABI 호환성을 주장하지 않는다. 엔진과 소비자 코드는 함께 재빌드해야 한다.
- 이번 정리에서 빌드·실행·성능 측정·새 테스트·로그 추가는 하지 않았다.
- 문서에 기재할 잔여 API 변경은 위 목록뿐이다. 과거 기록의 측정 결과를 현재 코드의 검증으로 재사용하지 않는다.
